# 🚀 Nexqor AI
### One Platform. Six Powerful AI Modules.

Nexqor AI is an AI-powered SaaS platform designed to bring business intelligence, project management, software development, documentation, and creative AI tools into one unified workspace.

Built with the MERN Stack, Nexqor AI aims to simplify complex workflows by providing intelligent tools for developers, entrepreneurs, project managers, and creative professionals.

---

## ✨ Core AI Modules

Nexqor AI offers six powerful AI modules:

### 1. 📊 Business Analysis
An intelligent business analysis tool designed to help users:
- Analyze business ideas and opportunities.
- Generate business insights and strategies.
- Identify potential challenges and solutions.
- Evaluate business concepts.

### 2. 📋 AI Project Manager
An AI-powered project management assistant that helps users:
- Create and organize project plans.
- Break projects into manageable tasks.
- Manage project workflows.
- Generate task suggestions and project insights.

### 3. 💻 AI Code Generation
An intelligent coding assistant that helps developers:
- Generate code from natural language prompts.
- Create programming solutions.
- Assist with different programming tasks.
- Improve development productivity.

### 4. 🔍 AI Code Analyzer
An AI-powered code analysis tool that helps developers:
- Analyze source code.
- Identify potential errors and bugs.
- Understand code functionality.
- Suggest improvements and optimizations.

### 5. 📝 AI Documentation
A smart documentation generator designed to:
- Generate Software Requirements Specifications (SRS).
- Create technical documentation.
- Generate project reports.
- Prepare structured development documents.

### 6. 🎨 Creative Studio
An AI-powered creative workspace for generating visual content.

**Features:**
- AI Image Generation.
- AI Video Generation.
- Creative visual content creation.

## ⚙️ Installation & Setup

Follow these steps to run Nexqor AI locally.

### 1. Clone Repository

git clone https://github.com/MuhammadHassanArif/NexqorAI.git

### 2. Navigate to Project

cd NexqorAI

### 3. Backend Setup

cd backend
npm install

Create a `.env` file inside the backend directory.

Configure your environment variables:


Start the backend:
npm run dev

Use the actual development script defined in `backend/package.json`.

### 4. Frontend Setup

Open another terminal:

cd frontend
npm install

Create a `.env` file inside the frontend directory:


Start the frontend:

npm run dev


## 🔐 Environment Variables

For security reasons, actual environment files are excluded from Git version control.

Required environment variables may include:

**Backend:**
- PORT
- MONGODB_URI
- JWT_SECRET
- GEMINI_API_KEY

**Frontend:**
- VITE_API_URL

Never upload API keys, database credentials, or secret tokens to GitHub.
